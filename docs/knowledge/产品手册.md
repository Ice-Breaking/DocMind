# DocMind 产品手册（示例知识库文档）

## 产品简介

DocMind 是一个知识助理 Agent，能够基于企业知识库回答事实性问题，并通过 MCP 协议调用外部工具获取实时信息。

## 核心检索流程

用户提问后，DocMind 按以下流程处理：

1. 用户提问进入 Agent
2. Agent 判断需要检索，调用 knowledge_search 工具
3. 问题文本被向量化（Embedding）
4. 与知识库切片向量做余弦相似度计算，取 Top-K
5. 检索到的文档片段作为上下文拼入 Prompt
6. 大模型基于上下文生成回答，并标注来源文件

## 文档切片策略

知识库文档按 500 字符滑窗切片，相邻切片保留 80 字符重叠，防止语义被截断。切片优先在换行处断开，保持段落完整。

## 支持的文件格式

当前支持 .md、.txt、.pdf、.docx、.xlsx、.png、.jpg、.jpeg、.webp 九种格式：PDF 用 pypdf 逐页提取，Word 用 python-docx 提取正文与表格，Excel 用 openpyxl 读取工作表，图片（PNG/JPG/JPEG/WEBP）通过 OCR 识别文字。单个文件解析失败只告警跳过，不影响其余文档建库。

## 常见问题

### 为什么回答里要标注来源？
为了可追溯和防幻觉。用户可以点击来源核对原文，模型也被要求只基于检索结果作答。

### 检索不到内容怎么办？
DocMind 会如实告知"知识库中没有相关内容"，而不是编造答案。可以尝试换一种问法或补充关键词。

### 如何新增知识？
把受支持格式的文档（.md、.txt、.pdf、.docx、.xlsx、.png、.jpg、.jpeg、.webp）放入 docs/knowledge 目录，重启应用即可自动重建索引。
