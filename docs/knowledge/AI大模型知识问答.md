# AI 大模型高频知识问答

## 一、大模型基础

### 什么是大语言模型（LLM）？
大语言模型是基于 Transformer 架构、在海量文本上预训练的神经网络模型，如通义千问、GPT 系列。它通过预测下一个词的方式学习语言的统计规律，具备问答、写作、代码生成等通用能力。

### 什么是 Token？
Token 是大模型处理文本的最小单位，中文场景下约等于 1～2 个汉字。模型的输入输出长度、计费都以 Token 为单位。控制上下文长度是控制成本的关键手段。

### Temperature 参数有什么作用？
Temperature 控制生成结果的随机性：值越低输出越稳定保守，值越高输出越多样有创意。知识问答类场景建议设为 0～0.3，创意写作可以调高。

## 二、RAG 检索增强生成

### 什么是 RAG？
RAG（Retrieval-Augmented Generation，检索增强生成）是"先检索、后回答"的技术方案：把用户问题向量化，从知识库中检索最相关的文档片段，拼入提示词让大模型基于这些材料作答。它解决了大模型知识过时和胡编乱造（幻觉）两大问题。

### RAG 的完整流程是什么？
1. 文档加载：读取知识库中的文件
2. 切片：按固定长度滑窗切分，保留重叠防止语义截断
3. 向量化：用 Embedding 模型把每个切片转成向量
4. 索引存储：向量存入向量数据库
5. 检索：用户问题向量化后做相似度计算，取 Top-K
6. 生成：检索结果作为上下文拼入提示词，模型作答并标注来源

### 什么是 Embedding？
Embedding（向量化）是把文本转换成高维数字向量的技术，语义相近的文本向量距离也近。它是语义检索的基础，常用模型有 bge 系列、text-embedding 系列。

### 如何提升 RAG 的检索质量？
常用手段包括：调整切片大小与重叠、混合检索（向量检索 + BM25 关键词检索）、重排序（Rerank）对初筛结果精排、查询改写（把用户口语问题改写成更适合检索的形式）。

### 向量数据库怎么选？
小规模原型用内存检索或 Chroma 即可；中等规模用 Milvus、Qdrant；已有 Elasticsearch 基础设施的企业可以用 ES 的向量检索能力。选型核心看数据规模、并发量和运维成本。

## 三、Agent 智能体

### 什么是 AI Agent？
AI Agent 是能自主规划并调用工具完成任务的大模型应用。核心循环是：思考（Reason）→ 行动（Act，调用工具）→ 观察（Observe，看工具返回）→ 继续或结束。这个模式叫 ReAct。

### Function Calling 是什么？
Function Calling 是大模型原生支持的工具调用能力：开发者用 JSON Schema 描述工具的参数格式，模型在需要时输出结构化的调用指令，由应用执行后把结果喂回模型。它是构建 Agent 的基础能力。

### Agent 如何防止死循环？
常见防护手段：限制最大推理步数、检测连续重复的工具调用并打断、工具异常不抛错而是返回错误描述让模型自我纠正、设置总超时时间。

### 为什么有人选择手写 Agent 而不用框架？
手写 Agent 核心循环代码量很小（百行以内），可以完全掌控上下文管理、异常处理和成本控制；同时能深入理解原理，方便排查框架黑盒问题。框架适合快速搭建复杂编排，手写适合追求可控和理解深度。

## 四、MCP 协议

### 什么是 MCP？
MCP（Model Context Protocol，模型上下文协议）是 Anthropic 提出的开放标准，定义了大模型应用与外部工具、数据源之间的标准化通信方式，可以理解为"AI 应用的 USB-C 接口"。

### MCP 的架构是怎样的？
MCP 采用客户端-服务器架构：MCP Host 是发起请求的应用（如 IDE、聊天工具）；MCP Client 与 Server 保持一对一连接；MCP Server 是轻量程序，暴露工具（Tools）、资源（Resources）和提示模板（Prompts）三类能力。

### MCP 支持哪些传输方式？
主要有 stdio（标准输入输出，适合本地进程）和 Streamable HTTP（适合远程服务）两种。本地工具集成常用 stdio，云端服务用 HTTP。

### MCP 和 Function Calling 是什么关系？
Function Calling 是模型层的工具调用能力，MCP 是应用层的工具接入协议。MCP 解决的是"工具从哪来、怎么标准化接入"的问题，Function Calling 解决的是"模型怎么决定调哪个工具"的问题，两者配合使用。

## 五、模型微调

### 什么是微调？
微调（Fine-tuning）是在预训练模型的基础上，用特定领域数据继续训练，让模型适配垂直场景。全参数微调成本高，实际常用 LoRA 等参数高效方法。

### 什么是 LoRA？
LoRA（Low-Rank Adaptation，低秩适配）是参数高效微调方法：冻结原模型权重，只训练旁路的小规模低秩矩阵。它显存占用低、训练快，且可以为不同任务保存不同的轻量适配层。QLoRA 进一步结合量化技术，让消费级显卡也能微调大模型。

### 预训练和微调的区别？
预训练是在海量通用语料上学习语言能力，成本极高；微调是在小规模领域数据上做针对性适配，成本低得多。预训练决定模型的能力上限，微调决定它在具体场景的表现。
