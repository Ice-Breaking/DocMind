## 钓鱼圈黑话
- 上岸：成功钓到鱼 / 达到预期渔获
- 报户：清点并上报当次渔获（通常指向钓场老板报鱼获重量）
- 拐老板 / 拐：钓获远超投入，让钓场老板亏本（"拐"= 赚老板的钱）
- 黑坑：商业收费钓塘（按时间/场次收费，钓获可回卖老板）
- 正钓：黑坑放鱼当天开钓的第一场
- 偷驴：非放鱼日去黑坑钓剩鱼，费用更低
- 上岸报户拐老板：每场都钓够本、报上好渔获、还能赚老板的钱

## 通用网络俚语
- YYDS：永远的神，表示极度认可
- 上岸（考公/考研语境）：成功通过考试被录取

## 相声 / 网络梗
- 二的妈妈酪三糖饼 / 烙三糖饼 / 二他妈妈：高英培相声《钓鱼》名梗，
  原为吹牛者钓鱼前让媳妇"烙糖饼"的桥段，现形容一本正经地胡说八道、
  或圈内人接暗号式玩梗
- 上岸报户拐老板：钓鱼圈连用黑话，见上

## 版本号 / 数字比较（高频歧义场景）
- 3.9 vs 3.11：软件版本号，3.11 > 3.9（次版本号11大于9，不是小数）
- Python 3.9 / 3.10 / 3.11：Python 语言版本，数字越大越新
- 版本号规则：主.次.修订（如2.1.0），从左到右逐位比较，不是小数运算
- 示例：1.10 > 1.9（次版本10>9），2.0.1 > 1.99.99（主版本2>1）

## 技术术语
- LLM / 大模型：Large Language Model，大型语言模型
- RAG：Retrieval-Augmented Generation，检索增强生成
- Token：模型处理的最小文本单元，中文约1.5-2字/token
- 上下文窗口：模型一次能处理的最大token数
- 截断：输出超长度限制被中断，需增大max_tokens或分段续写

## 时效性关键词（触发联网查询）
- 当前 / 最新 / 今年 / 今天 / 现在：需要实时信息
- 近期 / 最近 / 刚刚：通常指最近几天到几周
- 2026年 / 今年：需核实当前年份是否为2026年
- 新闻 / 热点 / 事件：需联网获取最新报道
